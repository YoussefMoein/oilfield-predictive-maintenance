## Publishing checklist

1. Create an empty repository on GitHub (no README, no licence - both are already here).
2. From this folder:
   ```bash
   git remote add origin https://github.com/<your-username>/oilfield-predictive-maintenance.git
   git push -u origin main
   ```
3. Paste the description and topics above into the repository's **About** panel.
4. Replace the `<your-username>` placeholders in `README.md` and `reports/linkedin_package.md`.
5. Add a licence of your choice (MIT is common for portfolio code) and your name to it.
6. Optional: upload `figures/15_risk_ranking.png` as the repository's social preview image.
